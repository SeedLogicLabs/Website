# SeedLogic Labs Website

## Project overview

Presumably the SeedLogic Labs company website; the name comes only from `package.json:2`
(`seedlogiclabswebsite`). The repo is a fresh `create-next-app` scaffold: one route (`/`),
placeholder copy, and default metadata (`app/layout.tsx:15-18`). No real content,
components, data fetching, or tests exist yet. Treat every convention below as the
scaffold's baseline, not a settled team decision.

## Key directories

- `app/` — App Router tree. `layout.tsx` is the root layout (html/body shell, fonts,
  metadata). `page.tsx` is the `/` route. `globals.css` holds Tailwind import and theme
  tokens. `favicon.ico` is served by file convention.
- `public/` — static assets served from `/` (currently scaffold SVGs referenced by
  `app/page.tsx:9` and `app/page.tsx:50`).
- `.claude/docs/` — extended docs for Claude (see "Additional documentation").
- `.next/` — build output and generated route types. Gitignored; never edit.
- `next-env.d.ts` — generated by `next dev` / `next typegen`. Gitignored
  (`.gitignore:41`); never edit.

Path alias: `@/*` maps to the repo root (`tsconfig.json:21-23`). There is no `src/`.

## Essential commands

Verified on this repo (Node 24, npm): `npm ci`, `npm run lint`, `npm run build`, and
the typecheck pair below. `dev` and `start` are the stock Next scripts.

```bash
npm ci                          # install from lockfile
npm run dev                     # dev server at http://localhost:3000
npm run build                   # production build (Turbopack); both routes prerender static
npm start                       # serve the production build
npm run lint                    # eslint (flat config, zero warnings today)
npx next typegen && npx tsc --noEmit   # typecheck
```

Typecheck notes:
- `tsc` fails cold with `Cannot find name 'LayoutProps'` because `LayoutProps<"/">`
  (`app/layout.tsx:20`) is a Next-generated global type. Run `npx next typegen` (or
  `next dev`/`next build`) first; it writes `.next/types/*` and `next-env.d.ts`.
- There is no `typecheck` npm script and no test runner configured. If tests are added,
  follow `node_modules/next/dist/docs/01-app/02-guides/testing/`.

`next dev` also maintains the managed `<!-- BEGIN:nextjs-agent-rules -->` block in
`AGENTS.md` (`node_modules/next/dist/server/lib/generate-agent-files.js`). It does not
touch this file while `AGENTS.md` exists, so keep `@AGENTS.md` as line 1 here.
